# Personal knife roll

The skills and tools I carry to every place I run agents. A cook brings their own knives to every restaurant, and I bring mine to every machine.

## Knives and rolls

**Knife**:
A skill or tool that an agent or I use to do a job. Standing instructions for agents are not knives.

**Personal knife roll**:
The knives I carry to every kitchen. It knows nothing about any employer.
_Avoid_: Knife set, personal set

**Restaurant knife roll**:
An employer's knives, which never leave that employer.
_Avoid_: House roll, house knife set

**Project knives**:
Knives that belong to one project's repo and go wherever that repo goes.
_Avoid_: Kitchen equipment

**Toolkit**:
A knife roll that a project turns on by name instead of copying from. The same roll can be one person's toolkit and another person's upstream.

## Places

**Kitchen**:
One place where agents run, with its own setup, such as a laptop, a cloud agent, or an employer's workspace.

## Other people's knives

**Adopt**:
To copy all or part of someone else's skill into the personal knife roll and record its upstream. The copy is then mine to edit.
_Avoid_: Vendor, install, fork

**Upstream**:
The repo, path and commit an adopted skill came from.
_Avoid_: Source, origin
